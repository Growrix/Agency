# Engineering memory — project template

Per `TP-ENG-SAASOS-001`. Copy this subtree when instantiating a new project engineering workspace.

## Folders

| Folder | Purpose |
|--------|---------|
| `programs/` | Engineering program roadmaps and briefs |
| `adr/` | Architecture decision records |
| `incidents/` | Incident postmortems |
| `benchmarks/` | Performance benchmarks |
| `runbooks/` | Operational runbooks |
| `changelogs/` | Release notes |
| `scorecards/` | KPI snapshots per `ST-ENG-SCORECARD-001` |

## meta.json

See `meta.json` in this folder — tracks, primary KPI, active program id.
