# Marketing memory — project template

Per `ST-GRO-MKT-MEMORY-001`. Copy this subtree when instantiating a new project marketing workspace.

## Folders

| Folder | Purpose |
|--------|---------|
| `brand-kit/` | Voice refs, logos (paths only), color/type notes — no secrets |
| `campaigns/` | One subfolder per campaign with charter, briefs, assets index |
| `winners/` | Post-mortems of campaigns that hit KPI |
| `losers/` | Post-mortems + lessons learned |
| `calendars/` | Editorial and channel calendars |
| `assets-index/` | Links/paths to creative assets (not binary dumps) |
| `scorecards/` | KPI snapshots per `ST-GRO-SCORECARD-001` |

## meta.json

See `meta.json` in this folder — mode (`client` | `product`), primary KPI, active campaign id.
