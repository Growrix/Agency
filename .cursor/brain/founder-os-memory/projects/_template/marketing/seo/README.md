# SEO memory — project template

Per `ST-GRO-MKT-MEMORY-001` and `TP-GRO-SEOOS-001`. SEO artifacts live under `marketing/seo/` for each project slug.

## Folders

| Folder | Purpose |
|--------|---------|
| `programs/` | SEO program briefs, roadmaps, post-mortems |
| `audits/` | Technical, on-page, off-page audit reports |
| `rankings/` | Ranking and visibility snapshots |
| `scorecards/` | Monthly SEO KPI scorecards |
| `algorithm-log/` | Algorithm update observations |
| `international/` | Hreflang maps, localization briefs |
| `ai-visibility/` | GEO / AI citation tracking notes |
