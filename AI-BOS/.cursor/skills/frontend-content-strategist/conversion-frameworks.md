# Conversion Frameworks

Ported patterns from HTML Products Builder + blueprint bp-07.

## One page, one goal

Each view should have a single primary conversion goal. Secondary links defer to footer or tertiary text links.

## CTA hierarchy

| Level | Placement | Copy style |
|-------|-----------|------------|
| Primary | Hero + sticky mobile CTA | Action verb + outcome |
| Secondary | Mid-page after proof | Lower commitment |
| Tertiary | Footer / nav | Informational |

## Trust signals

Place within 1 scroll of primary CTA:

- Client logos / certifications
- Review snippet or stat
- Risk reversal (guarantee, free consultation)
- Contact visibility (phone, local address when relevant)

## Pricing display

- Anchor value before price when applicable
- Clarify what's included
- One recommended tier highlighted

## Form discipline

- Minimum fields for goal
- Label + error text planned in CONTENT-BRIEF
- Success state copy defined before build

## Section narrative flow

Typical marketing homepage:

1. Hero — problem + promise + primary CTA
2. Proof — logos, stats, testimonials
3. Solution — features as outcomes not features
4. Process — how it works (3–5 steps)
5. Objection handling — FAQ or comparison
6. Final CTA — repeat primary action

Document this flow in CONTENT-BRIEF per project.
