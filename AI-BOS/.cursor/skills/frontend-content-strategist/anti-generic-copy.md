# Anti-Generic Copy Rules

Forbidden patterns in delivered content artifacts:

## Voice

- "Welcome to our website"
- "We are passionate about..."
- "In today's digital world..."
- "Leverage synergies" / empty corporate speak
- Generic "Get Started" without outcome context

## Structure

- Three identical feature cards with no differentiation
- Hero that is headline + subtitle + button only with no proof
- FAQ that restates marketing fluff

## Visual-language alignment

When blueprint or visual catalog specifies a style (editorial, brutalist, luxury, etc.), copy tone must match:

| Style | Copy tone |
|-------|-----------|
| Editorial | Authoritative, sentence variety, specific claims |
| Luxury | Restrained, precise, no hype adjectives |
| Technical | Spec-aware, measurable outcomes |
| Local service | Geographic specificity, trust, response time |

## Required specificity

Every CONTENT-BRIEF must include:

- Target audience segment
- Primary pain point
- Measurable or concrete outcome
- At least one proof element (stat, credential, case type)

If brief lacks business facts, mark `missing_knowledge` and ask user — do not invent client names or false stats.
