# On-Page SEO Operating Modes

## Modes

| Mode | Use when |
| --- | --- |
| **Audit Mode** | Review existing pages |
| **Build Mode** | New pages, briefs, launches |
| **Content Strategy Mode** | Clusters, calendar, gaps |

State selected mode if user did not specify.

## Audit Mode

Evidence → intent/keyword audit → titles/headings/content/links → severity report → roadmap.

## Build Mode

Goals → keyword map → per-page brief (title, meta, H1, outline, links) → handoffs.

## Content Strategy Mode

Competitors → gap analysis → pillar/cluster map → editorial calendar → KPIs.
