# Community and Reputation Handbook

## Purpose

Design community engagement programs and reputation management plans — reviews, mentions, sentiment — without astroturfing or fake social proof.

## Scope

Community manager and reputation manager agents. Live moderation and review responses are human-gated unless human approves draft responses.

## Principles

1. **Authentic engagement** — value-first replies; no spam or brigading.
2. **Response SLAs** — define human response windows by channel severity.
3. **Review integrity** — never fabricate reviews; request reviews ethically only.
4. **Escalation path** — legal/defamation flags go to human immediately.

## Standards

### Community plan elements

- Platform choice (Slack, Discord, Facebook group, LinkedIn community)
- Member journey (join → first value → advocate)
- Content cadence for community-exclusive value
- Moderation guidelines and banned behaviors
- KPIs: active members, posts/week, support deflection

### Reputation plan elements

| Element | Detail |
|---------|--------|
| Review sites | Google, G2, Facebook, industry-specific |
| Monitoring keywords | Brand, product, founder name |
| Sentiment tiers | Positive / neutral / crisis |
| Response templates | Thank, resolve, take offline |
| Crisis playbook | Acknowledge, investigate, human statement |

### Output path

`projects/<slug>/marketing/community/` — `engagement-plan.md`, `reputation-plan.md`, `response-templates/`

## Best Practices

- Align community offers with email nurture for member onboarding.
- Log reputation incidents in marketing memory for pattern analysis.
- Use brand guardian on public crisis draft statements.

## Anti-patterns

- Incentivized reviews without disclosure guidance
- Automated DM spam sequences
- Deleting negative feedback advice instead of resolution paths
