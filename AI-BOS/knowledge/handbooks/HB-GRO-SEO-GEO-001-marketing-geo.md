# AI Search and GEO Optimization Handbook

## Purpose

Guide **Generative Engine Optimization (GEO)** and AI search visibility — entity clarity, citation-worthy content, and keyword strategy that complements traditional SEO agents.

## Scope

Keyword research agent and GEO specialist. Technical SEO audits, Core Web Vitals, and on-page implementation remain with `AG-GRO-SEO-*` delivery agents and `HB-GRO-SEO-001`.

## Principles

1. **Answer-first content** — structure for direct answers AI systems can cite.
2. **Entity consistency** — brand, product, and founder entities named consistently across web and schema.
3. **Evidence and freshness** — dated stats, sources, and update cadence improve trust signals.
4. **No black-hat GEO** — no hidden text, fake citations, or review manipulation.

## Standards

### Keyword research deliverables

- Intent-classified clusters (informational, commercial, transactional)
- Priority matrix: volume band, difficulty estimate, business fit
- Mapping to content pillars and landing pages

### GEO deliverables

| Artifact | Focus |
|----------|-------|
| Entity map | Organization, product, person entities + sameAs targets |
| Citation playbook | Formats that earn references (original data, frameworks, checklists) |
| FAQ/HowTo blocks | Structured Q&A aligned to AI answer patterns |
| AI visibility audit | Baseline prompts to test brand mention (manual human run) |

### Collaboration with SEO agents

| Task | Owner |
|------|-------|
| Keyword clusters | Marketing GEO division |
| Technical crawl, schema implementation | AG-GRO-SEO-TECH-001 |
| On-page optimization | AG-GRO-SEO-ON-001 |
| Link building strategy | AG-GRO-SEO-OFF-001 |

### Output path

`projects/<slug>/marketing/seo-geo/` — `keyword-clusters.md`, `entity-map.md`, `geo-playbook.md`

## Best Practices

- Pair every commercial cluster with a dedicated landing page recommendation.
- Include "last updated" on pillar content briefs.
- Document human steps for Search Console and Bing Webmaster verification.

## Anti-patterns

- Guaranteeing #1 rankings or AI citation placement
- Keyword stuffing for LLM visibility
- Duplicating full technical SEO audits in GEO agent
