# Video Strategy and Scripts Handbook

## Purpose

Plan video funnel strategy and write scripts for ads, explainers, YouTube, and short-form reels that integrate with broader campaigns.

## Scope

Video strategist and script writer. Filming, editing, and upload are human-gated; thumbnail briefs route to creative division.

## Principles

1. **Hook in 3 seconds** — first line/visual direction mandatory for short-form.
2. **One video, one job** — educate, convert, or retain — not all three.
3. **Repurpose upstream** — scripts extend content pillars when possible.
4. **Platform format first** — aspect ratio and length targets stated in brief.

## Standards

### Video strategy deliverables

- Funnel role map (TOF awareness, MOF proof, BOF offer)
- Series architecture (episodes, cadence, CTAs)
- Distribution plan (YouTube, Shorts, Reels, paid cut-downs)

### Script template

```markdown
## Title / working name
## Length target
## Hook (0–3s)
## Setup
## Body beats
## Proof / demo notes
## CTA + end screen
## B-roll suggestions
## Captions / on-screen text
```

### Format guides

| Format | Length | Notes |
|--------|--------|-------|
| UGC-style ad | 15–30s | Problem → demo → CTA |
| Explainer | 60–120s | Chapter beats for retention |
| YouTube long | 8–15 min | Hook + pattern interrupts every 60–90s |
| Shorts/Reels | 15–45s | Text overlay script included |

### Output path

`projects/<slug>/marketing/video/` — `strategy.md`, `scripts/`, `shot-lists/`

## Best Practices

- Include Bangla human steps for upload, captions, and end-screen setup.
- Link scripts to repurposer maps from content division.
- Flag music/licensing as human responsibility.

## Anti-patterns

- Scripts without spoken-word line count for paid 30s slots
- Video strategy with no landing or lead destination
- Over-produced plan when client budget is phone-only UGC
